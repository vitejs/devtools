# AGDT0003: Integration Package Not Installed

## Message
> `{pkg}` is not installed in this project.

## Cause
An agent called a tool whose data comes from an integration package that cannot be resolved from the project directory. The Rolldown tools need `@vitejs/devtools-rolldown`; the Vite tools need `@vitejs/devtools-vite`.

## Example
Calling `vite:rolldown:agent:summary` in a project that installed only `@vitejs/devtools-agent`.

## Fix
Install the named package as a dev dependency and restart the dev server.

## Source
- [`packages/agent/src/node/integration.ts`](https://github.com/vitejs/devtools/blob/main/packages/agent/src/node/integration.ts) — `assertInstalled()` throws this before an integration's tool runs.
