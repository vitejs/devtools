# AGDT0002: Vite Inspection Not Active

## Message
> Vite inspection is not active in this project.

## Cause
An agent requested Vite inspection data while `@vitejs/devtools-vite` is installed but its inspector is not mounted.

## Example
Calling `vite:agent:modules` with `builtinDevTools: false` and without `DevToolsViteInspect()` registered, or before restarting after installing the package.

## Fix
Restart the dev server so the installed package is mounted. With `builtinDevTools: false`, explicitly register `DevToolsViteInspect()` alongside `DevToolsAgent()`.

## Source
- [`packages/agent/src/node/vite/index.ts`](https://github.com/vitejs/devtools/blob/main/packages/agent/src/node/vite/index.ts) — `inspect()` checks for the registered inspection RPC.
