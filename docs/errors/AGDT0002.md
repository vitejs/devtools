# AGDT0002: Vite Inspection Not Active

## Message
> Vite inspection is not active in this project.

## Cause
An agent requested Vite inspection data from a host without the Vite inspector.

## Example
Calling `vite:agent:modules` when only the agent integration is installed.

## Fix
Install `@vitejs/devtools-vite` and restart the dev server. With `builtinDevTools: false`, explicitly register `DevToolsViteInspect()` alongside `DevToolsAgent()`.

## Source
- [`packages/agent/src/node/vite/index.ts`](https://github.com/vitejs/devtools/blob/main/packages/agent/src/node/vite/index.ts) — `inspect()` checks for the registered inspection RPC.
