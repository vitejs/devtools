# AGDT0001: Rolldown Session Not Found

## Message
> Rolldown session "`{id}`" was not found in this project.

## Cause
An agent requested a build session absent from the selected project's recorded builds.

## Example
A session id from another project, or a deleted build, is passed to the summary tool.

## Fix
List recorded sessions on the selected instance and use a returned id. Generate a recorded build when the list is empty.

## Source
- [`packages/agent/src/node/rolldown/index.ts`](https://github.com/vitejs/devtools/blob/main/packages/agent/src/node/rolldown/index.ts) — `loadSession()` checks that the session belongs to the current project.
