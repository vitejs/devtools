# Chrome Extension

Bring Vite DevTools into Chrome DevTools.

![Chrome Extension for Vite DevTools](/features/chrome-extension.png)

## Installation

[Install on Chrome Web Store](https://chromewebstore.google.com/detail/vite-devtools/cibgffbjdnahlfohfhmjciehiihlgmdo)

## Usage

1. [Enable Vite DevTools](/guide/#installation) in your project.
2. Open your app in Chrome.
3. Open Chrome DevTools and select the Vite tab.

## Privacy

The extension checks for Vite DevTools locally in your browser. See our [privacy policy](/privacy) for details.
